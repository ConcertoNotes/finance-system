# 御洪智策 · 洪涝应急财经决策平台

按岗位组织的洪涝应急财经实训平台。左侧选择岗位，右侧出现该岗位的任务卡片，点击卡片进入任务操作台。

操作台不展示步骤说明，而是模拟真实业务系统：学生填表、勾选、点按钮执行一项操作，系统就给出该操作应有的回执，并解锁下一项操作。进度与已完成状态存在 localStorage，可随时重置。校验是真实生效的——数据源没测完、权重不等于 100%、分单没落在最优解、主供应商选错，都会被拦下并给出原因。

## 内容来源

平台的全部业务内容来自四份工作簿，**以工作簿为准，不做二次演绎**：

| 工作簿 | 作用 |
| --- | --- |
| `洪涝阶段一.xlsx` | 阶段一 5 个任务，按 4 个岗位分工作表 |
| `洪涝阶段二.xlsx` | 阶段二 6 个任务，按 4 个岗位分工作表 |
| `保险方案综合评分计算表.xlsx` | 阶段一任务4 的评分底稿 |
| `灾情数据成本动因转换计算表.xlsx` | 阶段一任务5 的测算底稿 |

### 任务编号

两份工作簿各自从「任务1」开始编号。平台把它们首尾相接：第一份的 5 个任务在前，第二份的 6 个任务接续为全流程的 6—11。

界面上不出现阶段字样。每个岗位页只显示该岗位承担的任务，并在岗位内从 1 连续编号，因此同一任务在不同岗位下的卡片号不同——例如「突发事件处置」是统筹岗的第 5 项、采购岗的第 7 项、风控岗的第 3 项。

| 岗位 | 承担任务 |
| --- | --- |
| 财务主管统筹岗 | 6 项 |
| 采购成本保障岗 | 8 项 |
| 应急预算绩效岗 | 5 项 |
| 资金核算风控岗 | 4 项（第一份工作簿中该工作表为空） |

「突发事件处置」是四岗协同的 16 步流程（外加统筹岗的决策步），任务详情页可在「本岗视角」与「全流程」之间切换。第二份工作簿中该任务缺少标题行，平台按内容补为「突发事件处置：S2库存异常与紧急分单」。

## 目录结构

```
scripts/                     Excel 解析与数据生成
  dump_xlsx.py               导出工作簿原始内容（含公式与计算值）
  compact_dump.py            生成便于阅读的紧凑文本
  build_tasks.py             生成 src/data/generated/taskContent.js
src/
  router/index.js            /role/:roleId 与 /role/:roleId/:taskKey
  layouts/AppLayout.vue      顶栏 + 岗位侧边栏 + 内容区
  views/                     首页、岗位任务页、任务详情、御洪星、补充数据表
  components/                任务卡片、步骤时间轴、内容块渲染
  components/panels/         11 个任务操作台（表单结构参考如易企业管理系统改编）
  data/                      岗位注册表、两张计算表数据、任务索引
  data/generated/            由 build_tasks.py 生成，请勿手工编辑
  domain/                    保险评分、成本动因、采购与分单求解
tests/                       任务结构与演算结果的回归测试
```

## 工作簿更新后如何重新生成

修改 `洪涝阶段一.xlsx` 或 `洪涝阶段二.xlsx` 后运行：

```bash
python scripts/build_tasks.py
```

生成器按工作表和行区间切分任务，配置集中在 `scripts/build_tasks.py` 顶部的 `STAGE1` / `STAGE2` 常量。若任务数量或行位置发生变化，需同步调整其中的行区间。

两张计算表的数值录入在 `src/data/insurance.js` 与 `src/data/costDriver.js`，同时以副本形式放在 `public/workbooks/` 供页面下载。

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建
npm test         # 回归测试
```

测试把所有关键数字锁回工作簿：保险综合得分 77.79、9网格预算 2,729,906、总预算 2,816,906、供应商 S2 88.3 分、初始预算占用率 25.29%、分单最优解 x1=150 成本 135,000、预备费使用 9,750。
