# 保险方案选择可编辑结果表设计

## 目标

在“救援人员保险方案比较”页面的标准分计算规则下方增加“方案选择”按钮。用户点击后，在页面内展开保险方案选择结果表。

## 交互与展示

- 默认只展示“方案选择”按钮；结果表不渲染。
- 点击按钮后显示两列表格，固定列为“项目”和“结果”。
- 固定项目依次为：综合得分最高方案、最高综合得分、保费（元）、支付资金来源、结论。
- 结果列采用与截图蓝色标记相近的浅蓝背景，以表明该列可编辑。
- 前四项使用单行输入框；结论使用可换行文本域。
- 初始值为 B保险公司、77.79、11000、政府财政拨款保障资金，以及现有计算表中的 B 方案结论。

## 数据与边界

- 编辑状态仅在当前组件会话内保存；刷新页面后恢复默认值。
- 此功能不修改报价表、权重、标准分规则或现有保险评分计算逻辑。
- 保持现有下载工作簿链接和页面布局风格。

## 验证

- 新增组件源码测试：确认方案选择按钮、条件渲染结果表、五个可编辑字段与默认值存在。
- 执行项目测试与生产构建。
