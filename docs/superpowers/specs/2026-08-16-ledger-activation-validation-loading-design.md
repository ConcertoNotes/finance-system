# 账套启用校验加载反馈设计

## 目标

为“校验测试并正式启用”操作增加约 3 秒的加载反馈，使用户在结果出现前看到明确的校验进行状态。

## 交互设计

1. 用户点击“校验测试并正式启用”。
2. 按钮立即进入加载状态：显示旋转圈和“校验中…”。
3. 加载期间按钮禁用，重复点击不会触发额外校验。
4. 约 3 秒后，执行现有账套启用校验逻辑。
5. 保留现有结果呈现：
   - 前置功能页均已完成时，显示各项通过及账套已启用信息。
   - 仍有前置功能页未办理时，显示现有未完成提示。
6. 校验结束后，按钮恢复可点击状态；若校验成功，仍由既有流程标记任务完成。

## 实现范围

- 仅调整 `yuhong-finance/src/components/panels/LedgerPanel.vue` 中 `ledger-activate` 页面。
- 增加组件内的校验中状态、3 秒延迟和按钮加载视觉样式。
- 不修改其他任务流程、校验规则或持久化数据结构。

## 测试

- 添加自动化测试，确认校验启动时进入加载状态、重复点击受阻，以及计时结束后再产生现有校验结果。
- 运行项目测试与生产构建验证。
