# 资金类别属性精简设计

## 目标
精简“专项账套 → 资金来源管理 → 新增资金类别”页中红线划掉的资金使用属性，只保留默认勾选的“是否限定用途”。

## 保留
- 资金来源标签区域。
- “限定性捐赠 → 开启用途强制校验”状态区域。
- “进一步设置资金使用属性”说明与“是否限定用途”复选框。

## 删除
- 限定使用网格及其选项。
- 限定物资类别及其选项。
- 到账时间、可支付时间、当前可用余额字段。
- 对已删除字段的响应式状态、计算属性、重置逻辑、保存校验与成功摘要。

## 行为
- `是否限定用途` 初始值和重置值均为已勾选。
- 保存仅校验保留的资金来源标签、用途强制校验和限定用途状态。
- 不引入依赖或改动其他业务页面。

## 验证
- 为页面源码添加回归断言：保留项存在，划掉项及相关状态不存在，限定用途默认已勾选。
- 运行项目测试和生产构建。
